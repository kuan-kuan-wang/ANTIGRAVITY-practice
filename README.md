# ANTIGRAVITY-practice (Flask 單頁式 Web 應用程式)

這是一個使用 Python Flask 框架建構的單頁式 Web 應用程式。

## 專案結構

```
ANTIGRAVITY練習/
├── app.py              # Flask 後端應用主程式
├── requirements.txt    # 相依套件清單 (Flask)
├── templates/
│   └── index.html      # 前端頁面範本
└── .gitignore          # Git 忽略檔案清單
```

## 快速啟動

1. **安裝相依套件**：
   ```bash
   pip install -r requirements.txt
   ```

2. **執行應用程式**：
   ```bash
   python app.py
   ```

3. **在瀏覽器中預覽**：
   開啟瀏覽器並前往 [http://127.0.0.1:5000](http://127.0.0.1:5000)
